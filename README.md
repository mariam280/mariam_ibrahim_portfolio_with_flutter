# Mariam Ibrahim Portfolio

A modern and responsive personal portfolio website built with Flutter Web to showcase my skills, projects, certifications, and experience in software development.
The portfolio highlights my journey as a Computer Science student and Flutter Developer, featuring my projects, technical skills, achievements, and ways to connect with me.

## Portfolio Link
https://mariam280.github.io/my_portfolio/

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Smooth scrolling and modern UI animations
* Personal introduction and About Me section
* Technical skills showcase
* Projects section with project highlights
* Contact section with social media links
* Downloadable CV
* Clean and organized code structure
* Flutter Web deployment support

## 🛠️ Technologies Used

* Flutter
* Dart
* Flutter Web
* Responsive UI Design
* Custom Widgets
* Animations
* Git & GitHub
* Figma AI
* GitHub Pages

## 🎨 Design Process

The portfolio UI was initially conceptualized using Figma AI based on prompts I created, then refined and implemented in Flutter Web to achieve the final responsive design.

## 💡 Sections Included

* Home
* About Me
* Skills
* Projects
* Contact

## 🎯 Purpose

This portfolio was created to present my technical skills, projects, and learning journey in a professional way while demonstrating my Flutter development abilities, UI implementation skills, and responsive web development experience.
